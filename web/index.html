Mines game. Click to reveal a square or chord an open number. Right-click to flag. Use arrow keys to move, Enter to reveal, Space to flag, F to toggle touch-friendly flag mode, R to restart, N for a new board. Reference or B cycles eight observed fixed boards at the original 20 pixel cell size. Descriptive Game IDs are shown. The flagged empty square replay applies real flag, reveal, unflag, and open-zero actions one step at a time. Q advances the replay. Undo and cumulative death history are outside this toy’s scope. Original size and Touch size switch the panel scale. This visual canvas game is a bounded reimplementation.
